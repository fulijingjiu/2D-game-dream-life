# 动作片段｜取弹、瞄准与投掷

**一张图：** 8 格，完整单次投掷。折叠雷管盒位于腰侧，炸弹独立成物件。

**模块属性：** 可供所有满足动作、装备与身体能力条件的角色调用，不因剧情角色或外观配置而专属；每份文档制作一张该动作的序列帧图。

## 逐格姿势

1. 侧身观察前方，手靠近腰侧雷管盒。
2. 打开盒盖，手指取出一枚雷管 / 炸弹。
3. 炸弹举到肩后，另一只手短暂指向落点，形成瞄准姿势。
4. 前脚踩稳，腰胯反向扭转蓄力。
5. 腰胯转回，手臂向前过肩挥出。
6. 手指放开；**投掷物生成帧**，弹体离手。
7. 手臂继续向前，躯干略倾，保持投掷方向。
8. 手回到腰侧，收势结束，可接移动。

炸弹只出现一枚，手部拿取和释放关系连续；不要让盒子里自动浮出多个炸弹。落点瞄准阶段可停留，不在图中画瞄准 UI。

## 序列帧制作简报

制作一张透明背景 8 格单行角色投掷序列。使用本次配置的角色模型，腰侧配置可替换的投掷物容器；从打开盒子取出一枚炸弹、肩后瞄准、转腰过肩投掷到收手。炸弹只在离手帧出现。无场景、敌人、文字、瞄准线、爆炸或声音元素。
