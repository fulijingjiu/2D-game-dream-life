# 角色技能动作设计

本目录把角色外观、装备、动作片段、技能规则和特效拆开管理。每份动作文档对应一个可复用动作片段，并规定一张单动作精灵表的姿势顺序。精灵表是制作 / 整理后的交付格式，不限定一定由某种软件绘制。

## 文档结构

- `2026-09-25-01-通用绘制规范.md`：画布、视角、格子、序列顺序、通用画面约束。
- `2026-09-25-02-角色视觉锚点.md`：主角与四位记忆角色的暂定外观配置，以及横斩样板的 22 色候选色板；不规定谁能使用哪项技能。
- `动作/`：按移动、近战、防御、投掷、攀爬等功能分类，一动作一文件。文件中的“序列帧制作简报”可用于 imagegen 逐张出帧（现行）、绘图软件修帧或 Blender 动作参考。
- `2026-09-25-技能总览.md`：技能规则、所需动作片段、装备需求和可配置角色；技能不绑定提供记忆的角色。
- `2026-09-25-03-模块化组合规则.md`：说明角色、装备、动作、技能和特效如何组合，以及何时才需要兼容条件。
- `参考资料/`：按制作、Godot 接入、AI 与深度图分类保存的官方 HTML 页面副本；具体来源与本地链接列在小白技术路线方案中。
- `2026-09-25-序列帧小样实施方案.md`：可复用序列帧小样的范围和验收标准（阶段计划基于 Blender 路线，已被现行路线取代，见文首现状对照）。
- `2026-09-25-角色序列帧技术路线小白方案.md`：零基础技术路线比较、推荐流程和官方入门资料（同上有对照说明）。

## 暂定约定

项目尚在早期阶段，目前初始武器、正式画风、像素尺寸和调色板都没有定稿。因此，角色外观建议标为暂定；先统一动作轮廓和装备识别，再根据最终美术方向替换细节。远程飞刃属于临时占位设定。动作文档中的“角色”是可替换的绘制主体；角色名只用于外观参考，不表示动作或技能的专属归属。

## 文件命名

所有 Markdown 文档使用 `2026-09-25-中文名称.md` 命名；动作子目录按功能分类，动作文件也带日期，例如 `动作/近战/2026-09-25-横斩.md`。文件中的主体、装备和特效通过配置替换；每张动作图只放一个动作，不混入其他动作、UI 或背景场景。

## 推荐制作路线

**2026-09-27 更新：现行主干是 imagegen 逐张生成完整角色帧。** 完整链路是
**imagegen 按提示词逐张出完整帧（`v4/source/`）→ `v4/build_sequence.py` 量脚底、查一致性、排布导出 →
Godot 4.7.2 按 manifest 播放与验证**。Pixelorama / CSP 仍可修帧，Blender 保留为备选路线。
AI 生成图**就是**正式帧的来源，但必须先通过脚本的一致性门禁（`--strict` 下不通过则不导出）——
取代了此前“AI 只作参考，不作为正式动作帧”的限制。
本地官方参考资料仍保存在 `参考资料/` 子目录。

## 本目录不包含

不设计音效、配音、音乐或声音提示；当前交付范围是动作与技术设计文档，不包含序列帧图片本身。
