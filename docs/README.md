# 《四烛》文档入口

本目录是设定、美术规格、原型记录和只读归档的唯一入口。正式设定只从下面三份读起，再顺着链接到动作稿和原型。

## 怎么读

1. [设定/故事框架](设定/故事框架.md)：第一步故事、Demo 范围，以及 **M0–M4 里程碑的唯一表**。
2. [设定/玩法探索](设定/玩法探索.md)：能力与关卡解锁。只引用故事框架里的里程碑，不另列一张。
3. [设定/技能总览](设定/技能总览.md)：技能、动作文档与 clip 的对应。M1 五动作链（跑 / 跳 / 落 / 落地 / 闪）写在这里。
4. [设定/关卡与场景清单](设定/关卡与场景清单.md)：节拍表、场景/道具/角色/敌人、音效需求标签；剧情关卡逻辑的生产拆解。

```
故事框架 M0–M4 → 关卡与场景清单（节拍）→ 技能总览（动作名 / clip）→ 美术/动作/*.md → 原型验收 + prototype/2d_pipeline/v4/
```

## 读写约定

- 交叉引用用相对路径。
- 禁止指向已删除的 V1–V3 目录、V2 帧表和三份 Blender 本地 HTML。
- `_archive/` 只读，不得作为资产命名、关卡标题或角色人数的依据。
- 里程碑状态只改 [故事框架](设定/故事框架.md) 里的那一张表。玩法探索和技能总览只引用，不复制整表。
- 色板一律称「现行 22 色板（方案 B）」，不要写成未定稿。

## 仍暂定清单

项目尚在早期阶段，下列各项仍可调整。此清单并入原《目录与使用说明》里的暂定约定；那份 00 文件已删除。

- 现行 22 色板（方案 B）尚未接进 `build_sequence.py` 导出。

## 文件命名

`设定/`、`美术/` 根下三份规范、`原型/横斩样板完成记录.md` 用中文短名，不带日期前缀。`美术/动作/` 保持原有日期文件名和功能子目录，例如 `美术/动作/近战/2026-09-25-横斩.md`。归档稿保留原日期文件名。每张动作图只放一个动作，不混入其他动作、UI 或背景。

## 推荐制作路线

**2026-09-27 起，现行主干是 imagegen 逐张生成完整角色帧。** 链路是 **imagegen 按提示词逐张出完整帧（`v4/source/`）→ `v4/build_sequence.py` 量脚底、查一致性、排布导出 → Godot 4.7.2 按 manifest 播放与验证**。Pixelorama / CSP 仍可修帧，Blender 保留为备选。AI 生成图就是正式帧的来源，但必须先通过脚本的一致性门禁（`--strict` 下不通过则不导出）。本地官方页面副本在 `参考资料/`。

## 本目录不包含

动作规格文档不规定音效波形实现。音效/音乐**需求标签**写在[关卡与场景清单](设定/关卡与场景清单.md)，由 design 挂接。序列帧图片本体在 `prototype/2d_pipeline/v4/`。
