# 界面动作｜地图显影

**一张图：** 6 格 UI 动画示意，不是角色序列帧。界面比例和颜色等 UI 风格确定后再精修。

**模块属性：** 地图显影属于 UI 能力反馈，不绑定角色模型、角色待机或战斗动作。

## 逐格内容

1. 当前已探索地图保持可见，未探索区域为留白。
2. 玩家位置出现一个简洁的路线印记。
3. 线框从已探索区域边缘向外扩展。
4. 当前关卡剩余布局以低对比度线条显现。
5. 已发现的出口、机关或收藏点依次亮起（只展示图标，不写文字）。
6. 显影稳定停留，回到地图静态状态。

不要把地图显影做成角色施法动作；不需要角色、手势、背景战场或额外装饰。早期地图入口灰置或仅小地图，全屏地图后期才开放（全文分期，不是 Demo 专属开关）。显影只负责在地图能显示之后，逐渐揭示未探索信息。

## 序列帧制作简报

制作一张透明背景 6 格单行游戏地图 UI 动画示意：从局部已探索地图，到路线线框向外展开，再显出关卡轮廓与少量无文字图标，最后稳定为完整地图。所有格地图位置与缩放一致，只有显影范围变化。无角色、文字、真实地形背景、边框装饰或声音元素。
