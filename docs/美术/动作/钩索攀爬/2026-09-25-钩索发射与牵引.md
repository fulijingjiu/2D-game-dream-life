# 动作片段｜钩索发射与拉近

**一张图：** 8 格，包含发射、受力移动和到点收势。钩索轨迹按程序端点连接。

**模块属性：** 可供所有满足动作、装备与身体能力条件的角色调用，不因剧情角色或外观配置而专属；每份文档制作一张该动作的序列帧图。

## 逐格姿势

1. 角色面向右，绳镖垂在腰侧，膝盖微屈准备起动。
2. 手腕向后收，躯干向左扭转，绳镖离开腰侧。
3. 持械臂快速向右甩出；**发射帧**。
4. 手臂伸直，绳线绷紧，身体开始前倾；明确绳线受力方向。
5. 双脚离地，身体沿斜向前伸展，另一手护住身体。
6. 被拉至锚点附近，膝盖收起，身体略转以减速。
7. 一脚先落地 / 接空中姿势，手臂仍抓住绳线。
8. 绳索松开，恢复战斗姿势，可接攻击或奔跑。

绳镖、绳线与角色为独立图层；绳线从手部接到画外 / 锚点方向，不在图中固定画出锚点。命中轻敌的拉拽对象由另一组敌人动画处理。

## 序列帧制作简报

制作一张透明背景 8 格单行角色钩索序列。使用本次指定的角色模型与旧训练绳镖装备外观；侧面朝右，从后收、甩出绳镖、绳索绷紧、身体被拉向前到落地松索。绳索清楚但不遮脸和四肢。无敌人、场景、锚点图标、文字或声音元素。
