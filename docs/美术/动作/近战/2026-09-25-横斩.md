# 动作片段｜基础近战第一击：横斩

更新日期：2026-09-27。当前主干（V4，imagegen 逐张完整帧）输出为 **8 帧、384×256 透明 PNG、朝右、总时长 620 ms**。
统一根点 (176,246)，逐帧时长与命中事件由 `v4/godot/assets/manifest.json` 管理。
下表是动作节拍与关键姿势，不是锁定的最终帧数；V3 曾用 12 帧 / 256×192 / 根点 (112,176) 实现同一动作，产物已删除。

**兼容：** 单手短兵器装备槽与侧视人形剪影。角色身份、服装与剑的造型分开配置；
但在当前路线里剑被画进整帧，运行时换不了武器，见下方“制作与组合”。

## 动作节奏

| 帧 | 姿势 | 停留时间（毫秒） |
| --- | --- | ---: |
| 01 | 战斗待机，剑在身前偏下 | 70 |
| 02 | 起手，收剑 | 90 |
| 03 | 蓄力峰值，重心压低、举剑 | 100 |
| 04 | 挥出起始 | 40 |
| 05 | 身前命中，触发 `hit` 事件（动作开始后第 300 ms） | 70 |
| 06 | 顺势跟随，围巾滞后 | 60 |
| 07 | 收势，缓冲余势 | 110 |
| 08 | 归位回待机，与首帧一致 | 80 |

08 与 01 是同一张图（构建脚本用 `shutil.copy2` 把 01 复制为 08，保证末帧能自然接回首帧）。
01–07 各由一张 imagegen 生成的源帧而来，源帧名见表下。

## 制作与组合

- 每帧由 imagegen 按 `v4/prompts/2026-09-26-0X-姿势名-生成提示词.txt` 单独生成，
  源图存在 `v4/source/`（`01-战斗待机`…`07-收势`）；03–07 各另有一份 `-武器修订提示词`。
- `v4/build_sequence.py` 负责量脚底、对齐到根点、跑一致性检查、缩放到导出网格、把不透明像素贴到现行 22 色板（方案 B）并排布。
  这把剑的形制已锁为单手直短刃，见[初始近战武器](../../初始近战武器.md)，不是 `relic_sword`。
  伤害、攻击范围与解锁规则不进入图片，由技能规则 / 程序维护。
- **分层现状：V4 做不到。** V3 曾按 `body → weapon → hands → fx` 合成并单独导出各层，
  现行路线画的是完整帧，剑和刀光烘在画面里，隐藏武器不会隐藏手部。
  需要换武器或换特效时只能对该组合重新逐帧生成。
- `hit` 只是接入判定系统的参考事件，本轮不包含敌人、伤害或声音。默认攻击结束回到 `idle`。
- 已知素材问题：**帧 06 在源图左边缘被切掉一部分**，画布留白不足，后续需要重新生成该姿势。
