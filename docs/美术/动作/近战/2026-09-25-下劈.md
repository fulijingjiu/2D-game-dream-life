# 动作片段｜基础近战第三击：下劈

> 全文后期片段。当前可交付近战 clip 只有 `slash`（横斩）。本稿保留姿势规格，不进当前排帧。

**一张图：** 7 格，连击收尾，强调重量和落点。

**模块属性：** 可供所有满足动作、装备与身体能力条件的角色调用，不因剧情角色或外观配置而专属；每份文档制作一张该动作的序列帧图。

## 逐格姿势

1. 从上挑后站姿开始，武器收于胸前。
2. 双手 / 持械手将武器举过肩，肘部弯曲。
3. 前脚踏出，躯干向前压；武器开始向下挥。
4. 武器沿斜线快速下落；**攻击判定开始**。
5. 刀锋到达身体前下方最低点；**判定末帧**。如攻击地面目标，可加独立小火花效果。
6. 膝盖屈曲吸收挥击，武器停留低位。
7. 抬起武器，回到战斗待机；此段收招略慢于前两击。

## 序列帧制作简报

制作一张透明背景 7 格单行下劈序列。角色面向右，短兵器从肩上举起、向前下方重劈，低姿收势后恢复站姿。攻击弧不能遮住头脸；不画敌人、地面、背景、文字、火花或声音元素。
