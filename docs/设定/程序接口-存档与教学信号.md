# 程序接口：存档与教学信号

本页是给程序和 UI 的字段与信号合同。故事、技能、节拍仍以[故事框架](故事框架.md)、[技能总览](技能总览.md)、[关卡与场景清单](关卡与场景清单.md)为准。这里不改里程碑状态，也不另写一套规则。

**里程碑只卡验收，不删字段。** M0–M4 做到哪一步只看故事框架那一张表。存档从第一天起就带全文键。M1 不烧资源、不改烛火公式；这些键保持初值，留给后面的回点与盾痕。

## 1. 存档

`anchor_id` 只有 `wenlan` | `mojiu` | `xiaohe` | `qishuang`。烛档、回应按这个 id 存，不要用显示名当键。

| 键 | 类型 | 取值 | 初值 | 谁来写 |
| --- | --- | --- | --- | --- |
| `candle_tier.<anchor_id>` | 枚举 | `full` \| `waver` \| `weak` \| `dying` | 四座都是 `full` | 战斗消耗与回点强化以后写。回点 UI 只读。M1 不改 |
| `shard_wenlan` `shard_mojiu` `shard_xiaohe` `shard_qishuang` | bool | `true` / `false` | `false` | 该记忆门通关时置 `true` |
| `relic_shield` | bool | `true` / `false` | `false` | 盾痕**关中**、弹体 / 压力板路**之前**拾取时置 `true` |
| `response.<anchor_id>` | 枚举或空 | `trust` \| `doubt` \| `silence` \| `null` | 全 `null` | 见下文写入条件 |
| `gate_wenlan` `gate_mojiu` `gate_xiaohe` `gate_qishuang` | 枚举 | `open` \| `locked` \| `cleared` | 闻岚 `open`，其余 `locked` | 通关改 `cleared`，下一扇 `locked` → `open` |
| `hub_panels_unlocked` | bool | `true` / `false` | `false` | 从至少一扇已 `cleared` 的记忆门**返回回点**时置 `true` |
| `event_hero_echo` | bool | `true` / `false` | `false` | 四枚 `shard_*` 都为 `true` 时置 `true` |

禁止出现 `memory_shard` 这个字段，也不要用它做计数器。散文里的「记忆碎片」不是存档键。门和碎片分两笔写：通关时该 `gate_*` 改 `cleared`，对应的 `shard_*` 置 `true`。不要用其中一个代替另一个。

下一门顺序：`gate_wenlan` 之后是 `gate_mojiu` → `gate_xiaohe` → `gate_qishuang`。四枚碎片都为真才把 `event_hero_echo` 置真；少一枚就保持 `false`。

`relic_shield`：

- 0B 把盾放上锚台只是演出，不写旗标。
- 关中拾取写 `true`，盾反从此可用。这是永久旗标。
- 关底「领取」只播演出，不得再写一次、不得发临时盾、不得改回 `false`。

`response`：

- `null` 表示还没问。`silence` 是玩家选了沉默，不是空。
- 只有 `hub_panels_unlocked == true` 之后才允许写成 `trust` | `doubt` | `silence`。也就是至少从一扇已通关的记忆门返回之后。
- 每座锚台各一格，允许改写。抗性公式不在本接口，也不进苏醒预览。

新档示例：

```json
{
  "candle_tier": {
    "wenlan": "full",
    "mojiu": "full",
    "xiaohe": "full",
    "qishuang": "full"
  },
  "shard_wenlan": false,
  "shard_mojiu": false,
  "shard_xiaohe": false,
  "shard_qishuang": false,
  "relic_shield": false,
  "response": {
    "wenlan": null,
    "mojiu": null,
    "xiaohe": null,
    "qishuang": null
  },
  "gate_wenlan": "open",
  "gate_mojiu": "locked",
  "gate_xiaohe": "locked",
  "gate_qishuang": "locked",
  "hub_panels_unlocked": false,
  "event_hero_echo": false
}
```

## 2. 回点初访

`hub_panels_unlocked == false` 的第一次进回点：

- 四支烛只读（初访都是 `full`）。
- 离开方式是已经点亮的门（初访只有 `gate_wenlan = open`）。
- **强化、残响回应、苏醒预览不创建节点。** 不是灰掉、不是禁用后仍可点。

返回且至少一扇记忆门已 `cleared` 之后，`hub_panels_unlocked` 改为 `true`。这三个面板才出现：强化、残响回应、苏醒预览。苏醒预览只读，确认才结算。

## 3. Beat 0C 教学信号

状态机发信号，UI 听。FSM 不负责把提示做成控件，也不按教学进度锁操作。每次发生都发，可以重复。UI 自己按顺序锁存「这段已经见过」。

教学顺序：跑 → 跳 → 落 → 落地 → 斩 → 闪。

| 顺序 | 动作 | 信号 | 何时发 |
| --- | --- | --- | --- |
| 1 | `run` | `tut_run_started` | 进入 `run` |
| 2 | `jump` | `tut_jump_started` | 进入 `jump` |
| 3 | `fall` | `tut_fall_started` | 进入 `fall` |
| 4 | `land` | `tut_landed` | 进入 `land` |
| 5 | `slash` | `tut_slash_started` | 进入 `slash` |
| 6 | `dodge` | `tut_dodge_ended` | **离开** `dodge`（结束，不是起手） |

从平台边缘走空也会发 `tut_fall_started`。闪的信号只在结束时发，所以 UI 要等 `tut_dodge_ended` 才算这一段教完。

## 4. M1 状态机

无资源。不扣烛、不走冷却。

`godot/assets/idle` 与 `godot/assets/slash` 是待删的弯刃旧帧，**不是**交付样本。直刃形制和色板锁定之后由设计重导（#8）。在那之前，骨架对 `idle` / `run` / `jump` / `fall` / `land` / `dodge` / `slash` **全部**用 ColorRect 占位，不读取这些 PNG，也不用它们的二进制差做断言。缺文件不得退出。

对着旧弯刃帧的 M0 `main.gd --verify` **已经退役**。验收等这次形制锁定后的重导。重导之前 `jump` → `fall` 只看升顶；`land` / `dodge` / `slash` 的毫秒只写在 `player_fsm.gd`，不是设计锁。

`dodge` 是无敌帧翻滚，不是祁霜的窄缝瞬步 `blink`。这条状态机没有 `blink`。

衔接（与已合并的 M1 约定一致）：

| 从 | 到 | 条件 |
| --- | --- | --- |
| `idle` | `run` | 有水平方向 |
| `run` | `idle` | 松开方向 |
| `idle` / `run` | `jump` | 跳跃 |
| `jump` | `fall` | 升顶。重导之前没有 `jump` 帧可播完。**不能**从 `jump` 直接 `dodge` |
| `idle` / `run` / `fall` | `dodge` | 闪避 |
| `fall` | `land` | 接地，且这一帧闪还没起手 |
| `land` | `idle` | 落地段结束，没有方向 |
| `land` | `run` | 落地段结束，仍有方向 |
| `dodge` | `idle` | 结束、脚在地上、没有方向 |
| `dodge` | `run` | 结束、脚在地上、仍有方向 |
| `dodge` | `fall` | 空中闪结束仍离地；或地上闪中途失去地面 |
| `idle` | `slash` | 攻击 |
| `slash` | `idle` | 斩击段结束 |
| `idle` / `run` | `fall` | 走下平台边缘（没有 `jump`） |

`land` 播完之前不接闪、跳、攻击。`slash` 只从 `idle` 起手，M1 不从斩击段中途切去五动作链。同一帧多键、人在地上且是 `idle`/`run` 时：闪避优先于跳跃，跳跃优先于攻击，攻击优先于跑。这样「跳和闪同一帧」不会变成从 `jump` 里闪。

骨架入口（`main.tscn` 仍是旧播放器；弯刃 `--verify` 不再作为通过条件）：

```bash
prototype/2d_pipeline/v4/run_m1.sh
prototype/2d_pipeline/v4/run_m1.sh --headless -- --m1-check
```

场景是 `res://player_m1.tscn`。需要本机 Godot 4.7.2，二进制放在仓库根目录 `tools/godot-4.7.2/Godot_v4.7.2-stable_linux.x86_64`。这条场景不读旧弯刃帧。`run_demo.sh` 的 `main.tscn` 只留下给旧播放器，不再拿来验收。

## 5. 默认输入

M1 场景在 `_ready` 里补上下表（已有同名动作且已绑该键则不重复加）。旧 `main.tscn` 若还在，空格仍直接播斩，不读这张表，也不再当作验收。

| 动作名 | 用途 | 默认键 |
| --- | --- | --- |
| `move_left` | 左 | `A`、左方向键 |
| `move_right` | 右 | `D`、右方向键 |
| `move_up` | 上（不是跳） | `W`、上方向键 |
| `move_down` | 下 | `S`、下方向键 |
| `jump` | 跳跃 | `Space`、`K` |
| `dodge` | 闪避翻滚 | `Shift`、`L` |
| `attack` | 近战，进 `slash` | `J`、`Z` |

横版骨架只用水平轴。`move_up` / `move_down` 先挂在映射里，避免把 `W` 当成跳跃。

## 6. 初始近战握点（暂定）

形制板 1280×720：正 / 侧 / 刃口三视，加上持剑角色。粉十字质心约为画板坐标 **(873, 315)**。

```text
WEAPON_GRIP_SHEET_PX = (873, 315)
```

这个数**只属于形制板**。它不是 gameplay 根点，也不是 `manifest.json` 的 `root_px`。设计把每条 clip 的握点偏移锁死之后，Godot 必须改用**相对该帧精灵**的握点。在那之前不要拿 `(873, 315)` 当挂剑原点或伤害点。

初始近战的武器 id 是 `starter_melee`。它不是 `relic_sword`（祁霜旧练习剑，刺击外观）。
