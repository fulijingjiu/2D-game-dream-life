# 关卡与场景清单（第一步）

> **用途：** 把[故事框架](故事框架.md)拆成可生产的节拍表：场景、道具、出场角色、敌人、机关、音效/音乐需求。@design 按本表挂资产与音效；@coding / @UI 按节拍对接入点。盾拾取、碎片字段、回点初访与游玩序与故事框架、技能总览同一套全文规则。
>
> **权威关系：** 故事规则与 M0–M4 仍以故事框架为准；能力解锁以[玩法探索](玩法探索.md)为准；技能/clip 以[技能总览](技能总览.md)为准。Demo 范围 = 开场 + 回点 + 第一关（盾痕），表中标 **Demo**。Demo 是里程碑子集，不是平行规则。
>
> **游玩路径：** `0C(M1)→hub(M3)→盾痕(M2+M4)`。能力编号仍是 M2→M3→M4，编号不是出场顺序。

## 1. 全局逻辑闭环（必须能讲通）

```
最后一战倒下 → 四人献锚施术 → 结界醒来（失忆）
    → 出口光被弹回（目标：四份记忆）
    → 回点初访：只读四烛 + 从已亮的门离开
    → 记忆关取碎片/技能（盾痕的盾在弹体路前拾取）
    → 返回回点：残响回应 + 可选强化（初访没有）
    → 四碎片齐 → 英雄回声战 → 出口开
    → 苏醒结算（预览只读，确认=结算；由过程烛火累积）
```

**因果约束（写关卡时不许打破）：**

1. 死因与敌方主谋第一步不揭示；开场敌人只作剪影/压迫感。
2. 守关回声 ≠ 同伴本人；残响才是同伴声音。
3. 技能消耗记**锚台 id**（wenlan / mojiu / xiaohe / qishuang），不记皮肤。
4. 主线不要求旧关回访才能推进；回访只给支路/收集。
5. Demo 无远程；开场教学 = **M1 五动作链**（跑→跳→落→落地，闪从 idle/run/fall 插入）+ 已有 `slash`；不以「移/跳/闪」简称漏掉落与落地。M1 状态机无资源。
6. 碎片存档键只有 `shard_wenlan|mojiu|xiaohe|qishuang`。散文里的「记忆碎片」不是字段，不要写 `memory_shard`。
7. 地图是全文分期：早期入口灰置或仅小地图；全屏地图后期开放。不是「仅 Demo 关掉全屏」。

**锚台 id（给程序/UI）：** `wenlan` | `mojiu` | `xiaohe` | `qishuang`  
**烛火四档：** `full` → `waver` → `weak` → `dying`（对应完整/摇晃/微弱/近熄）  
**碎片存档：** `shard_wenlan` | `shard_mojiu` | `shard_xiaohe` | `shard_qishuang`（布尔）。没有 `memory_shard` 字段。

**回点循环（完成至少一扇记忆门并返回后；初访不走 2–3，也没有苏醒预览）：**

1. 写入本关 `shard_wenlan` / `shard_mojiu` / `shard_xiaohe` / `shard_qishuang` → 可回听该角短残响。散文里的「记忆碎片」不是存档键。  
2. **残响回应**三选一：信任 / 质疑 / 沉默 → 改该角供锚意愿与后续台词；轻微影响该烛消耗抗性（信任略缓、质疑略促，沉默中性）。这列抗性不出现在苏醒预览面板上。  
3. 可选**强化**（标锚台+预代价，可取消）。  
4. 观察四烛 → 开下一门或（四碎片齐）触发英雄回声事件。苏醒预览只读；确认 = 结算。

## 5. 残响回应 → 逻辑效果（可程序化）

| 回应 | 对该锚台 | 叙事 |
| --- | --- | --- |
| 信任 | 后续同技能消耗略减（缓一档阈值）；残响偏温 | 「我还认你这份额」 |
| 质疑 | 消耗略增；残响带刺仍供锚 | 「你凭什么用我的记忆」 |
| 沉默 | 无数值偏置；残响最短 | 未表态 |

不影响能否通关；只影响台词、供锚意愿表现、苏醒关系细节权重。

消耗抗性与预览代价的公式随 M2 / 回点交付，不挡 M1。M1 状态机无资源（`run` / `jump` / `fall` / `land` / `dodge` / `slash`）。苏醒预览面板不展示这列抗性；预览只读，确认 = 结算。回应要等至少完成一扇记忆门并返回后才出现。

## 6. Demo 最小闭环检查单

- [ ] 0A→0B→0C→回点初访→盾痕→回点残响，约 10–15 分钟。游玩路径 `0C(M1)→hub(M3)→盾痕(M2+M4)`  
- [ ] 初访回点只有只读四烛和闻岚门；无强化、无回应、无苏醒预览  
- [ ] 盾痕在弹体/压力板之前拾取盾并写下 `relic_shield=true`；关底演出不再次授予、无临时盾、不卸下  
- [ ] 碎片只写 `shard_wenlan` 等四键，无 `memory_shard` 字段  
- [ ] 玩家能复述：为何在结界、四人用何物救他、技能耗哪座锚台、下一步找什么  
- [ ] 闻岚烛至少发生一档可见变化（战斗耗 + 返回后的一次回应）  
- [ ] 无远程、无死因揭示、墨九门可只作「已看见的下一目标」
