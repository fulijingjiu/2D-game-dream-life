# 玩法探索草稿：角色能力与关卡解锁

> 本稿结合《四烛》第一步故事框架，参考《重生细胞》的符文尺度做能力分配。目标是让四段记忆各自教会一项清晰的新能力，并用它打开新的战斗或探索方式；本稿只做设计草案，不涉及代码实现。
>
> **2026-10-15：** 烛火消耗跟解锁来源 / 锚台；Demo 先砍开场远程。原型里程碑只维护在[故事框架](故事框架.md)，本稿只引用，不另列表。场景/道具/音效节拍见[关卡与场景清单](关卡与场景清单.md)。

## 设计原则

1. **基础操作所有关卡通用。** 开场即可使用 **M1 五动作链**（跑、跳、落、落地、闪）与近战。近战 clip 名是 `slash`，旧帧已撤，待按形制图重出；上挑、下劈是后期。**Demo 不含远程**；远程投掷仅作占位草案。五段 clip 与状态机衔接以[技能总览 · M1](技能总览.md#m1-五动作链)为准。M1 状态机无资源。第一段闻岚回忆教盾反（M2），不把基础移动拆成后期解锁。
2. **每位角色提供一项固定的记忆能力。** 能力一旦解锁就永久可用：盾痕的盾在关中拾取时解锁，其余三项在通关对应回忆时解锁。不切换角色、不建立四套角色等级，也不做庞大技能树。
3. **一项能力解决一个清楚的问题。** 能力既有战斗用途，也能改变路线或打开特定交互。玩家第一次看到对应机关时，能从图标和环境读出能力用途。
4. **地图是探索工具，不占战斗技能槽。** 这是全文分期，不是 Demo 专属开关：早期地图入口灰置，或只保留小地图；全屏地图后期开放。祁霜的「显影」负责揭示未探索部分与重点位置，不把全屏地图提前到开场。
5. **奖励规模参考符文。** 《重生细胞》的藤蔓、蜘蛛、Ram、传送符文分别提供攀爬、贴墙、破地面和使用传送点等明确新规则；Explorer’s Rune 则在探索大部分关卡后揭示地图与兴趣点。这类能力直接改变通路或信息，不需要做成多层技能树。符文用途链接是社区维护资料，更新说明链接来自游戏官网。[符文与能力资料（社区 Wiki）](https://deadcells.wiki.gg/wiki/Ram_Rune) [官方更新说明](https://deadcells.com/patchnotes/15)

## 能力与角色匹配

建议教学顺序：**基础操作 → 闻岚 → 墨九 → 小禾 → 祁霜**。这样从近战与防守，逐步走向投掷爆破、垂直探索，再用高机动能力和地图信息完成综合探索。

| 解锁来源 | 固定解锁能力 | 烛火消耗锚台 | 战斗用途 | 探索用途 | 专属遗物 |
| --- | --- | --- | --- | --- | --- |
| 开场：基础操作 · **M1** | 跑→跳→落→落地；闪可插入；近战 clip 为 `slash`（旧帧已撤，待按形制图重出；上挑、下劈后期；Demo 无远程）。clip：`run`/`jump`/`fall`/`land`/`dodge`/`slash`。状态机无资源 | 无 | 一段近战、躲避攻击 | 跨越常规平台、通过普通门和梯子 | 初始近战武器；不绑定某一人的锚物 |
| 第一关：闻岚 | **盾反**：按时格挡可弹开攻击并造成硬直；按住则普通防御。弹体 / 压力板路之前关中拾取盾并写入 `relic_shield=true`；关底领取是演出 | 闻岚 | 破招、守住狭窄空间、保护角色 | 挡住机关发射物，触发压力机关 | 裂纹圆盾（永久旗标；不发临时盾、不卸下） |
| 第二关：墨九 | **爆破工具**：投掷炸弹，可主动引爆或等待延时爆炸 | 墨九 | 范围伤害、打断成群敌人、布置连锁爆炸 | 炸开有明显标记的脆弱墙面与地板 | 折叠雷管盒 |
| 第三关：小禾 | **钩索攀行**：钩住指定锚点拉近；在标记墙面短暂附着并向上攀 | 小禾 | 拉近轻型敌人、空中接招、脱离包围 | 跨过断层、攀上标记墙面、抵达高处路线 | 旧训练绳镖 |
| 第四关：祁霜 | **瞬步**（`blink`）+ **刺击**：短距离窄缝步，可穿过窄缝或躲过部分攻击；精准时机后的追击窗口可接刺击。追击窗口不是单独技能 | 祁霜 | 瞬步后刺击、贴近远距离敌人 | 穿过短距离裂隙、越过危险地带、连接短平台 | 旧练习剑 |
| 探索升级：祁霜记忆中的战场观察 | **地图显影**：探索到当前关卡大部分区域后，揭示整张地图和重点位置 | 祁霜（若强化绑定该记忆；纯 UI 浏览不耗烛） | 不直接造成伤害，也不占主动技能槽 | 找到未走通的路线、机关、收藏物和出口 | 地图印记 / 祁霜的路线记录 |

**`dodge` ≠ `blink`：** `dodge` = 无敌帧翻滚；`blink` = 窄缝瞬步（祁霜）。祁霜技能只记瞬步 + 刺击，以及地图显影；「弹反追击」只是瞬步后的追击窗口，不是单独技能。

## 解锁节奏与旧路回访

- 闻岚关后，玩家有完整基础操作和防御能力，可以处理常规敌人与防御机关。
- 墨九关后，旧关卡里带裂纹标识的障碍可被炸开，出现短支路、补给或收集物。
- 小禾关后，带钩索标识的锚点和攀爬墙变为可用；地图可出现此前看得见但到不了的垂直区域。
- 祁霜关后，瞬步打开短距离断层；追击窗口里可以刺击。通关后获得地图显影，方便玩家清理遗漏路线。
- 能力门槛只用于可选支路、捷径和收集物；主线不能要求玩家反复回头才能继续第一步故事。

第一步只有四个记忆关，因此能力数量保持在四项角色能力加基础操作。Ram 符文式的重击破地面和传送符文式的传送点可以作为后续能力备选，不必都塞进第一步。

## 地图交互

地图按全文分期，不另写一套「仅 Demo 关闭」的规则：

- **早期：** 地图入口灰置，或只保留小地图。开场不能打开全屏地图。
- **后期：** 开放全屏地图，显示已走过的区域、当前房间和已经发现的出口。
- **地图显影：** 祁霜记忆解锁的探索能力。玩家走过关卡大部分区域后，揭示未探索布局和兴趣点；这是对《重生细胞》Explorer’s Rune 的尺度参考，而不是复制其触发比例或具体图标。显影不把全屏地图提前到开场。

《重生细胞》的基础控制表把查看地图列为常规操作；它的 Explorer’s Rune 才负责在探索大部分关卡后揭示地图。本稿早期不开放全屏地图，只借用显影的尺度。[控制说明](https://deadcells.wiki.gg/wiki/Controls) [Explorer’s Rune 介绍](https://deadcells.wiki.gg/wiki/Ram_Rune)

## 第一关和 Demo 的教学稿

建议 Demo 做 **禁术开场 + 回点 + 闻岚关**（无远程）：

1. 开场短片里主角在最后一战倒下，四人献出锚物施展禁术。
2. 回声结界内按 **M1** 教跑→跳→落→落地，并教闪与近战；出口光被弹回，提示玩家要找回记忆。教学顺序细节见[关卡与场景清单 Beat 0C](关卡与场景清单.md#beat-0c--结界初醒与教学--demo--对应-m1)。
3. 初访回点只读四烛，从闻岚门进入盾痕。不开放强化、残响回应、苏醒预览。
4. 闻岚关先用普通敌人教攻击和闪避。弹体 / 压力板路之前拾取裂纹圆盾，写入 `relic_shield=true`，再用盾挡与盾反通过该段并打守关（盾反对应故事框架里的 M2，不在 M0 验收）。关底「领取」只是演出：不再次授予、不发临时盾、不卸下。击败守关回声后写入 `shard_wenlan`。
5. 返回四烛回点后才解锁残响回应、强化和苏醒预览（预览只读，确认 = 结算，面板不含回应抗性），看到闻岚锚台的烛火因战斗使用和回应选择产生变化。墨九记忆关入口作为 Demo 后续目标。

里程碑状态以[故事框架的原型里程碑表](故事框架.md)为准，本稿不复制 M0–M4。

**验收重点：** 玩家能区分开场就能使用的基础操作、记忆解锁的固定能力，以及早期地图（入口灰置或仅小地图）、后期全屏地图和祁霜地图显影；并理解技能消耗的是对应锚台烛火。
