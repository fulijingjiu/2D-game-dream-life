# 程序接口：挂帧约定

本页只锁 M1 主角 `idle` / `slash` 怎么交帧，以及以后程序怎么把色块占位换成图。状态机衔接、`tut_*`、存档键仍以[程序接口-存档与教学信号](程序接口-存档与教学信号.md)为准。这一轮不把贴图挂进场景。

## 1. 占位留到两道闸

`idle` / `run` / `jump` / `fall` / `land` / `dodge` / `slash` 继续用色块占位。两道都过之前不换贴图：

1. **负责人口味通过。**
2. **美术自检过闸：** 同尺寸画布、共脚钉、握点不漂、`slash` 为 `01`–`07` 且顺序符合姿势板、透明底。

文件还没交、或只过了一道，场景照常跑。缺文件不得退出。

## 2. 画布与脚钉

`idle` 与 `slash` 每一张画布同一像素尺寸。全组共用一条脚底基线（脚钉），对齐已锁的横斩 **7 格姿势板**。脚底中心不逐帧上下漂，也不逐帧左右挪。`idle` 种子钉在同一条基线上。

## 3. 轴心与握点

- **轴心：** 脚底中心。腰与这条脚钉在同一竖线上，用来核对身体没有逐帧横移。腰不另做逐帧字段。
- **握点：** 手→刃根是常量，只认形制图 [初始近战三视+握点](../美术/形制/初始近战-三视握点.jpg)。形制板粉十字 `(873, 315)` 只标注那张板。交进来的 `grip_px` 是这个挂点在帧精灵上的像素，`idle` 与 `slash` 全组同一个数，不得逐帧漂移，也不把 `(873, 315)` 写进 manifest。

## 4. 片段

| clip | 帧 | 播放 | 顺序 |
| --- | --- | --- | --- |
| `idle` | ≥ 1 | 已认可的种子帧。本页不把呼吸循环扩成固定格数 | 种子能接回自身 |
| `slash` | `01`–`07` | **10 fps**（每格 100 ms） | 跟姿势板备注：预备（ready）→ … → 收势（recover） |

不在这 7 格之外加阶段。`run` / `jump` / `fall` / `land` / `dodge` 仍无帧，不在本次交付里。

## 5. 交付

两种都可，不要混用：

- 透明 PNG，逐帧同一尺寸；或
- 一张图集，外加 manifest 里的矩形。

manifest 在画布之外至少带这两个全组常量：

| 字段 | 含义 |
| --- | --- |
| `foot_pivot_px` | 脚钉。脚底中心，精灵原点，`[x, y]` |
| `grip_px` | 握点像素，相对该帧精灵，`[x, y]` |

图集矩形只描述裁切，不单独改轴心。clip 名用 `idle`、`slash`。数值等帧交齐再填，本页不预写像素。

## 6. 程序只换路径

两道闸都过之后，程序只替换贴图路径和 manifest 路径。不改 FSM 衔接，不改 `tut_*` 的名字和发出时机，不改存档键。

## 7. 受击盒

hurtbox 后置。以后再近似全身一盒加刃尖一盒。本页不锁矩形，握点也不是伤害点。

## 8. 生产母带

文档是权威。攻击和 `slash` 只挂 **棍板 + 手层** 管线烘出的帧。视频抽帧不是这条生产母带。

`_retired-*` 下已退役的 AI 候选，以及已作废的弯刃预览，都不是金样本，也不作为挂帧来源。
