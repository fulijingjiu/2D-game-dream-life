# 2D 动作游戏第一步故事框架

> 当前采用版本：暂名《四烛》。本稿只覆盖第一步：四人以禁术救回主角，主角穿过回声结界、取回生前记忆，最后醒来。主角的死因留给后续篇章。
>
> 本稿是这一步的**全文设计**。后文 Demo（开场 + 回点 + 盾痕）只是里程碑子集，不是另一套规则。
>
> **2026-10-15 拍板：** 烛火消耗绑定「记忆锚台 / 解锁来源」，不跟当前皮肤；Demo 先砍开场远程；色板采用现行 22 色板（方案 B），见[角色视觉锚点](../美术/角色视觉锚点.md)。备选故事已归档为废案，见[故事概念](../_archive/2026-09-25-故事概念.md)，**不得**写入本步美术、关卡标题或角色人数。修订过程见[设定稿修订方案](../_archive/2026-10-15-设定稿修订方案.md)（已落实，勿当现行）。

## 故事核心

最后一战中，主角倒下。四位同伴不接受他的死亡，强行施展禁术，把各自珍藏的一件锚物和一段共同记忆投入仪式。主角被拽进由四份记忆拼成的回声结界，几乎忘了自己是谁，只听见远处传来四道熟悉又陌生的声音。

结界中央有一道看似出口的光。主角每次靠近，都会被结界弹回。要离开这里，他必须穿过四段记忆、击败守在其中的回声怪物，取回四位同伴交出的记忆和遗物。每次使用某段记忆解锁的战斗技艺，也会加深对应锚台的烛火代价（跟解锁来源，不跟当前外观皮肤）。

四关通关后，主角记起自己如何生活、与四人如何相识，也终于能认出他们的声音。他在现实中醒来，但没有想起自己为何而死。第一步结束于重逢，以及四人记忆被禁术改变后的状态。

**核心问题：** 四个人能不能用彼此珍视的记忆，换回一个人？救回来的主角，醒来时又会留下谁的记忆？

## 禁术与结界规则

1. 禁术名暂定「四烛回生」。四人各交出一件锚物，并把与主角的一段共同记忆点作烛芯。四份记忆在结界中形成回点与四条记忆关卡。
2. 这次禁术会救回主角，但献出的记忆不会自动归还。主角可以在结界中找回它们；四人的记忆能否恢复、恢复多少，取决于禁术过程中烛火被消耗的程度。
3. 回点中央设四支记忆烛和四座锚台，分别对应闻岚、祁霜、墨九、小禾。烛火越低，表示该人失去的记忆越多；熄灭意味着他或她将不再记得与主角最重要的那段关系。
4. 烛火消耗绑定**记忆锚台 / 解锁来源**，不绑定当前外观皮肤。装备并使用「某段记忆解锁」的技能或遗物时，借用的是对应锚台的烛火；例如岑举着裂纹圆盾施展盾反，消耗仍记在闻岚烛上。使用倾向越明显，该锚台消耗越多。消耗按阶段累积并通过烛火高度表现，不要求玩家追踪复杂数值。叙事可继续写「用某人的技艺」；实现与 UI 一律记「消耗对应记忆锚台」。装配条件见[技能总览](技能总览.md)。
5. 回点强化也会加深对应锚台的代价。每次确认强化前，界面直接指出受影响的锚台与预计代价；玩家可以取消。强化要等**至少完成一扇记忆门并返回回点**后才解锁；初访没有强化。
6. 从记忆关返回回点后，主角可通过残响回应该角色：信任、质疑或沉默。回应会影响该人是否继续稳定禁术、是否愿意承受更多消耗。初访不能回应。回应改变的消耗抗性不画在苏醒预览面板上。
7. 记忆守关者是由遗憾、恐惧和残留战斗意志形成的回声怪物，不代表同伴本人。击败它能让主角取回对应记忆碎片。遗物一般随该关解锁。**盾痕例外：** 裂纹圆盾在弹体 / 压力板路之前的关中拾取，写入 `relic_shield=true`；关底「领取」只是演出，不再次授予、不发临时盾、不卸下。闻岚碎片仍在关底写入 `shard_wenlan`。

## 主要角色与战斗奖励

| 角色 | 交出的锚物 / 记忆 | 战斗技艺 | 专属遗物 | 可能付出的记忆代价 |
| --- | --- | --- | --- | --- |
| 闻岚，盾卫 | 裂纹圆盾；主角第一次把她从绝境中带出来的那天 | 盾反、格挡、守住狭窄阵地 | 裂纹圆盾 | 忘记自己为何愿意跟随主角，或忘记那次获救的细节 |
| 祁霜，剑士 | 旧练习剑；两人最后一次约定公平决斗的记忆 | 瞬步 + 刺击；地图显影 | 旧练习剑 | 忘记两人曾是对手与伙伴，或忘记最后的约定 |
| 墨九，爆破手 | 折叠雷管盒；主角相信他、把关键爆破交给他的那次任务 | 雷管投掷、连锁引爆 | 折叠雷管盒 | 忘记主角对他的信任，或忘记一次共同完成的任务 |
| 小禾，学徒 | 旧训练绳镖；主角第一次答应收她为徒的记忆 | 钩索位移、空中连击 | 旧训练绳镖 | 忘记师徒关系，或忘记两人最后一次训练 |

主角「岑」（暂名）开局几乎没有生前记忆。他在每关取回的碎片让他记起一个具体经历，逐步恢复身份、关系和战斗本能；每位同伴的武器与动作也成为可装备的回声兵装。

> **表注：** 「战斗技艺」列是**记忆解锁来源**，不是运行时专属绑定。谁能装备由能力 / 装备条件决定；早期装备条件是永久解锁旗标，装备画在帧里，不做运行时换装。烛火仍记在上表对应角色的锚台上。
>
> `dodge` = 无敌帧翻滚；`blink` = 窄缝瞬步（祁霜）。祁霜只记「瞬步 + 刺击」和「地图显影」；「弹反追击」只是瞬步后的追击窗口，不是单独技能。

## 第一部流程

### 0. 开场：最后一战与禁术（约 2–5 分钟）

开场先给最后一战的短片段：主角倒下，四人冲到他身边。无需解释敌人和死因，只表现他们不肯放手。四人各自交出锚物和记忆，合力发动禁术。

主角在回声结界中醒来，几乎空白，只听见四道声音。玩家学习 **M1 五动作链**（跑 → 跳 → 落 → 落地；闪从 `idle`/`run`/`fall` 插入，不从 `jump` 直插）与近战普攻；clip 约定见[技能总览 · M1](技能总览.md#m1-五动作链)。远处有一道明显的出口光，靠近后被无形屏障弹回。屏障给出直接目标：找回散落在结界中的四份记忆。

### 1. 枢纽：回点

回点位于结界中央，由四支记忆烛和四座锚台组成。

**初访**（还没有完成任何一扇记忆门）：只能阅读四支烛的高度，并从已经亮起的记忆门离开。不开放强化、残响回应、苏醒预览。

**至少完成一扇记忆门并返回之后**才解锁：

- 整理已取回的记忆碎片，听见对应同伴的残响，并作出回应。
- 强化技能或遗物；确认前标出会加深哪位同伴的代价，可以取消。
- 苏醒预览。面板只读，展示四烛现状与预计结果；确认 = 结算。回应带来的消耗抗性不出现在这块面板上。

回点画面固定，让玩家一眼比较四人的状态。烛火从完整、摇晃、微弱到近乎熄灭分层显示，不展示复杂的数值条。分区、分态和字段绑定见[回点 HUD 线框](../美术/回点HUD线框.md)（线框，不出图）。

### 2. 四关主循环

四关先按固定顺序呈现，保证基础操作逐步增加。每关遵循：**进入记忆 → 战斗与机关 → 关底回声怪物 → 写入该关 `shard_*`（及该关技能 / 遗物）→ 回到回点后才回应同伴**。

**盾痕：** 裂纹圆盾不在关底授予。弹体 / 压力板路之前的关中拾取写入 `relic_shield=true`。关底「领取」只是演出：不再次授予、不发临时盾、不卸下。`shard_wenlan` 仍在关底写入。

| 关卡 | 记忆主角 | 记忆内容与转折 | 技能 / 遗物 | 关卡特色 |
| --- | --- | --- | --- | --- |
| 第一关：盾痕 | 闻岚 | 主角与闻岚第一次并肩作战。闻岚记得自己被主角救下；碎片补出她曾违令折返，也救过主角。 | 盾反、守势 / 裂纹圆盾（关中拾取） | 拾盾之后才教格挡、盾挡弹体和护卫型敌人。 |
| 第二关：引线 | 墨九 | 一次爆破任务失控。墨九记得自己犯了错；碎片让主角看见他曾把唯一安全的引爆机会交给墨九。 | 雷管连锁 / 折叠雷管盒 | 教投掷、延迟引爆和环境连锁；炸开带裂纹标识的障碍。 |
| 第三关：收徒那天 | 小禾 | 主角第一次答应收小禾为徒。记忆里既有她学会战斗的喜悦，也有她不愿再被留下的恐惧。 | 钩索位移、标记墙攀爬 / 旧训练绳镖 | 教锚点移动与垂直路线，开放此前可见但到不了的区域。 |
| 第四关：未完之约 | 祁霜 | 两人约好任务结束后决斗。回声反复演练胜负，记忆碎片揭示他们早已把竞争当成彼此的信任方式；关底留下主角最后一战的模糊身影，不揭示死因。 | 瞬步 + 刺击 / 旧练习剑；地图显影 | 教窄缝瞬步，以及瞬步后的追击窗口（不是单独技能）；取回祁霜的战场路线记忆后，探索大部分区域可显影地图与兴趣点。 |

每次从记忆关返回回点，才可回应刚完成记忆的角色。回应会改变残响台词和供锚意愿；相应技能或遗物的高频使用也会增加该人的烛火消耗。剧情让玩家逐渐理解：禁术正在用四人的记忆维持主角的回归。

### 3. 通关战：英雄回声

四份碎片拼齐后，四人的战斗记忆在回点汇成「英雄回声」。它不是最终反派，而是四个人心中不同版本的主角：永远正确、从不畏惧、一定能救所有人的完美英雄。

玩家要用四关学会的技能打败这个形象，认回真实的自己，也看见四人施展禁术的原因和代价。胜利后出口开启，主角恢复生前记忆；唯独最后一战的死因仍被一片空白隔开，留给后续篇章。

### 4. 苏醒：第一步的终点

主角在现实中醒来，场景只需病榻或仪式后的房间，不再追加一整场葬礼剧情。烛火结算此前的技能使用、回点强化和回应选择；苏醒结果来自过程累积，不在结尾临时弹出三选一。

| 累积结果 | 苏醒后的关系状态 |
| --- | --- |
| 四烛消耗较均衡 | 四人都记得主角，也都失去一小段共同记忆；关系仍在，细节模糊。 |
| 消耗明显偏向一人 | 该人忘记与主角最珍贵的一段往事，其他三人只失去较淡的细节。 |
| 一支烛火近乎熄灭 | 对应的人醒来后认不出自己与主角曾有多亲近；其他人的记忆相对完整。 |

通关前可以查看四烛现状与苏醒预览（至少完成一扇记忆门并返回后才解锁；初访没有）。预览只读，确认后直接结算。预览用于告知代价，不提供重新分配记忆的按钮，也不展示回应的消耗抗性。

## 莲花图：第一步故事发散

莲花图用于规划主题，不作为游戏地图。中心问题是：**四个人付出的记忆，能把主角救回到什么程度？**

八个花瓣：最后一战与禁术、回点与四烛、闻岚的盾痕记忆、祁霜的未完之约、墨九的引线记忆、小禾的师徒记忆、英雄回声、苏醒后的关系结果。每个花瓣再展开角色目标、记忆事件、敌人和机关、技能遗物、烛火代价、残响回应、情绪变化及结尾影响。

## Demo 范围

首个可玩 Demo 做 **开场禁术 + 回点 + 闻岚第一关**，时长约 10–15 分钟。它验收上文全文规则在这个子集里的样子，不另写盾、回点或地图规则。**Demo 先砍开场远程**（无飞刃 / 远程投掷教学与帧需求）；远程仍作占位草案，不进本 Demo 验收。

1. 用最后一战和禁术演出建立目标，不解释主角死因。
2. 在回声结界完成 **M1**（`run`/`jump`/`fall`/`land`/`dodge`，外加按形制图重出的 `slash`）教学，用出口屏障说明闯关目的。无远程。这条状态机无资源。旧 `slash` 样板已撤。
3. 初访回点：只读四烛，从闻岚门离开。不开放强化、回应、苏醒预览。
4. 盾痕：弹体 / 压力板路之前拾取裂纹圆盾，写入 `relic_shield=true`，再教盾挡与盾反。关底领取是演出，不第二次给盾。击败守阵回声，写入 `shard_wenlan`。
5. 返回回点后才有闻岚残响和一次回应（强化与苏醒预览也在这次返回后解锁），烛火因此可见变化，并显示下一段记忆入口。

## 后续篇章边界

第一步只写到主角醒来。醒来后他记得自己和四人如何共同生活，却不记得自己为何倒下；第二步再从死因展开，本稿不预设凶手、事故或完整续篇剧情。
