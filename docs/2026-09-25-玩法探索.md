# 玩法探索草稿：角色能力与关卡解锁

> 本稿结合《四烛》第一步故事框架，参考《重生细胞》的符文尺度做能力分配。目标是让四段记忆各自教会一项清晰的新能力，并用它打开新的战斗或探索方式；本稿只做设计草案，不涉及代码实现。
>
> **2026-10-15：** 烛火消耗跟解锁来源 / 锚台；Demo 先砍开场远程；原型里程碑与故事框架一致（M0–M4）。

## 设计原则

1. **基础操作所有关卡通用。** 主角从开场就能移动、奔跑、跳跃、下落、近战和闪避。**Demo 不含远程**；远程投掷仅作占位草案。第一段闻岚回忆负责正式教学，不把这些常用输入拆成数个后期解锁门槛。
2. **每位角色提供一项固定的记忆能力。** 主角通关对应回忆后永久学会该能力，之后始终可以使用；不切换角色、不建立四套角色等级，也不做庞大技能树。
3. **一项能力解决一个清楚的问题。** 能力既有战斗用途，也能改变路线或打开特定交互。玩家第一次看到对应机关时，能从图标和环境读出能力用途。
4. **地图是探索工具，不占战斗技能槽。** 从开场即可打开全屏地图查看已探索区域；后续再解锁“显影”能力，揭示当前关卡未探索部分与重点位置。
5. **奖励规模参考符文。** 《重生细胞》的藤蔓、蜘蛛、Ram、传送符文分别提供攀爬、贴墙、破地面和使用传送点等明确新规则；Explorer’s Rune 则在探索大部分关卡后揭示地图与兴趣点。这类能力直接改变通路或信息，不需要做成多层技能树。符文用途链接是社区维护资料，更新说明链接来自游戏官网。[符文与能力资料（社区 Wiki）](https://deadcells.wiki.gg/wiki/Ram_Rune) [官方更新说明](https://deadcells.com/patchnotes/15)

## 能力与角色匹配

建议教学顺序：**基础操作 → 闻岚 → 墨九 → 小禾 → 祁霜**。这样从近战与防守，逐步走向投掷爆破、垂直探索，再用高机动能力和地图信息完成综合探索。

| 解锁来源 | 固定解锁能力 | 烛火消耗锚台 | 战斗用途 | 探索用途 | 专属遗物 |
| --- | --- | --- | --- | --- | --- |
| 开场：基础操作 | 移动、奔跑、跳跃、闪避、下落、基础近战（Demo 无远程） | 无 | 普通攻击组合、躲避攻击 | 跨越常规平台、通过普通门和梯子 | 初始近战武器；不绑定某一人的锚物 |
| 第一关：闻岚 | **盾反**：按时格挡可弹开攻击并造成硬直；按住则普通防御 | 闻岚 | 破招、守住狭窄空间、保护角色 | 挡住机关发射物，触发压力机关 | 裂纹圆盾 |
| 第二关：墨九 | **爆破工具**：投掷炸弹，可主动引爆或等待延时爆炸 | 墨九 | 范围伤害、打断成群敌人、布置连锁爆炸 | 炸开有明显标记的脆弱墙面与地板 | 折叠雷管盒 |
| 第三关：小禾 | **钩索攀行**：钩住指定锚点拉近；在标记墙面短暂附着并向上攀 | 小禾 | 拉近轻型敌人、空中接招、脱离包围 | 跨过断层、攀上标记墙面、抵达高处路线 | 旧训练绳镖 |
| 第四关：祁霜 | **瞬步**：短距离快速位移，可穿过窄缝或躲过部分攻击；精准时机可接追击 | 祁霜 | 闪避后反击、追击远距离敌人 | 穿过短距离裂隙、越过危险地带、连接短平台 | 旧练习剑 |
| 探索升级：祁霜记忆中的战场观察 | **地图显影**：探索到当前关卡大部分区域后，揭示整张地图和重点位置 | 祁霜（若强化绑定该记忆；纯 UI 浏览不耗烛） | 不直接造成伤害，也不占主动技能槽 | 找到未走通的路线、机关、收藏物和出口 | 地图印记 / 祁霜的路线记录 |

## 解锁节奏与旧路回访

- 闻岚关后，玩家有完整基础操作和防御能力，可以处理常规敌人与防御机关。
- 墨九关后，旧关卡里带裂纹标识的障碍可被炸开，出现短支路、补给或收集物。
- 小禾关后，带钩索标识的锚点和攀爬墙变为可用；地图可出现此前看得见但到不了的垂直区域。
- 祁霜关后，瞬步打开短距离断层和攻击窗口。通关后获得地图显影，方便玩家清理遗漏路线。
- 能力门槛只用于可选支路、捷径和收集物；主线不能要求玩家反复回头才能继续第一步故事。

第一步只有四个记忆关，因此能力数量保持在四项角色能力加基础操作。Ram 符文式的重击破地面和传送符文式的传送点可以作为后续能力备选，不必都塞进第一步。

## 地图交互

地图分成两种功能：

- **全屏地图界面：** 从开场即可打开，显示玩家已走过的区域、当前房间和已经发现的出口。它是基础界面功能。
- **地图显影：** 祁霜记忆解锁的探索能力。玩家走过关卡大部分区域后，揭示未探索布局和兴趣点；这是对《重生细胞》Explorer’s Rune 的尺度参考，而不是复制其触发比例或具体图标。

《重生细胞》的基础控制表把查看地图列为常规操作；它的 Explorer’s Rune 才负责在探索大部分关卡后揭示地图。[控制说明](https://deadcells.wiki.gg/wiki/Controls) [Explorer’s Rune 介绍](https://deadcells.wiki.gg/wiki/Ram_Rune)

## 第一关和 Demo 的教学稿

建议 Demo 做 **禁术开场 + 回点 + 闻岚关**（无远程）：

1. 开场短片里主角在最后一战倒下，四人献出锚物施展禁术。
2. 回声结界内教移动、奔跑、跳跃、近战和闪避；出口光被弹回，提示玩家要找回记忆。
3. 进入闻岚记忆关，用普通敌人教攻击和闪避，再用一次明显的盾击教盾反（属里程碑 M2，不在 M0 验收）。
4. 击败守关回声后获得裂纹圆盾与盾反能力，回到四烛回点，看到闻岚锚台的烛火因战斗使用和回应选择产生变化。
5. 地图上显出墨九记忆关入口，作为 Demo 后续目标。

原型里程碑：**M0 横斩 → M1 跑跳闪 → M2 盾反 → M3 回点四烛白盒 → M4 闻岚关最小循环**（详见故事框架）。

**验收重点：** 玩家能区分开场就能使用的基础操作、记忆解锁的固定能力，以及地图界面和地图显影的不同；并理解技能消耗的是对应锚台烛火。
