# 主角造型与像素制作规范

版本：3.0（完整横斩样板）  
适用范围：主角模型、正侧背视图、侧视战斗序列帧、后续换装与技能动作。  
主参考图：[2026-09-26-主角三视图像素重绘.png](reference/2026-09-26-主角三视图像素重绘.png)

> **2026-09-27 / 2026-10-15 现状对照。** 第 1–3 节的造型识别与剪影规则仍然有效。
> **第 4 节色值已于 2026-10-15 按方案 B 回写为 v4 实测的[现行 22 色板（方案 B）](v4/config/palette.candidate.json)**（文件名仍带 `candidate`；旧设计意图色作废案）。
> 第 5–9 节是 V2/V3 Blender 2.5D 路线的规格与验收，产物已删除，下文用历史时态记录，不再作为现行导出标准：
> 现行主干是 imagegen 逐张完整帧，导出画布 384×256、根点 (176,246)、横斩 8 帧，
> 由 `v4/build_sequence.py` 和 `v4/godot/assets/manifest.json` 管理，不存在 `Hero_*` 对象与 `HeroRig` 骨架。

## 1. 设计目标与识别顺序

主角是被四位同伴以禁术救回的人。初醒时记忆不全，外观要让玩家先记住“被缝合的记忆”，再记住一个能投入战斗的年轻人。角色不穿满身盔甲，不靠大量挂件堆叠细节；识别点按以下优先级固定：

1. 左肩垂下的暗朱红破围巾：远景第一识别点，动作时负责提供方向和速度感。
2. 腰带中央的黄铜记忆匣：四条不同颜色的玻璃芯，对应四位同伴的记忆锚点。
3. 右鬓一缕银白发：近景识别点，象征复生后记忆中的缺口。
4. 胸口衣襟下方的环状缝合痕：禁术留下的身体印记；衣服静止时只露出一部分，受击或大动作时可见。
5. 右臂米白绷带、左臂深色护腕：不对称轮廓，表达救治与战斗经验。

玩家在游戏实际显示尺寸下，先读出头发、短外套和围巾的整体剪影；缩小到 64px 高时仍须保留红围巾和头部银发亮点。腰匣与缝合痕是近景细节，允许在小尺寸下简化，但不得替换其位置和主色。

## 2. 三视图统一基准

参考图画布为 **1536 × 1024 px，RGB**，依次为正面、严格左向侧面、背面。图像用于造型和比例校对，不直接当作游戏透明精灵图，也不能用三视图裁切后拼动作。视图中的人物必须维持同一头身、肩宽、腰线、膝线、靴底高度和服装长度。

建模比例以全身高度 **H = 1000 单位**（靴底到发顶）为基准，左右对称的身体结构以正面图为准，不对称服饰以正面图定义左右，再用侧面和背面延续。面向方向的“左/右”均按角色自身左右说明，不按屏幕左右说明。

| 部位 | 高度范围（从靴底向上） | 宽度基准 | 制作要点 |
| --- | ---: | ---: | --- |
| 鞋底与靴子 | 0–105 | 肩宽的 0.30–0.36 | 深棕靴，浅灰米色底边；靴头圆钝，靴筒有两道横向固定带 |
| 小腿与膝部 | 105–365 | 单腿约 0.20 肩宽 | 深炭色裤，膝部有折线和磨损面；关节处不要画成膨大护甲 |
| 大腿与腰胯 | 365–535 | 髋宽约 0.72 肩宽 | 裤腰被腰带遮住；正面两侧各有一片小口袋轮廓 |
| 腰带与记忆匣 | 490–560 | 腰带围绕躯干 | 记忆匣宽约 0.21 肩宽、高约 0.075H，放在身体正中；四芯顺序固定为琥珀、青绿、乳白、朱红 |
| 躯干与外套 | 520–790 | 肩宽 = 1.00 | 深墨蓝短外套敞开，外套下摆至大腿上段，分成左右两片尖角衣尾 |
| 头颈 | 790–1000 | 头宽约 0.38 肩宽 | 成年比例；头部不做大眼幼态；下颌、鼻梁和耳朵在侧面要清楚 |
| 围巾 | 颈部至约 260 | 主体不超过肩宽 | 朱红布从左肩扣点垂下，最长略过膝；只留一条主尾，不增加第二条飘带 |

以上数值是绘制及建模的标尺，允许布料外轮廓在动作中摆动；身体骨架尺寸、腰匣位置与鞋底基线不得随动作漂移。

## 3. 视图逐项说明

### 正面

- **头发：** 墨黑短发，顶部有 5–7 组清晰发束；角色右鬓一束银白发从发际延伸至耳上（正面视图在画面左侧），不扩大成整片白发。额发略遮一侧眉，但双眼仍可辨认。
- **面部：** 眉形偏直，眼睛正常成年比例；鼻梁和嘴角线克制。默认表情警惕、疲惫，不画怒吼或笑容。鼻、眼、嘴在战斗精灵小尺寸下可做像素化简化。
- **内层：** 骨白色交叠布衣，领口在胸骨处交叉；胸前可见暗色环形缝合痕的上半段。胸口印记不是项链，也不是徽章。
- **外套：** 深墨蓝，翻领略高于肩；左右衣襟不完全对称，边缘有细窄冷灰蓝缝线。衣襟内侧露出骨白内衫。
- **肩扣与围巾：** 朱红围巾从角色左肩的黄铜扣固定，沿身体左侧垂下；正面必须看到扣件和围巾主体。布尾是磨损裂口，不是整齐剪裁的三角旗。
- **腰带：** 深棕皮带，黄铜矩形扣；中央记忆匣内四芯必须可区分，腰带两侧只留一条短垂带和一枚小环。
- **手臂：** 角色右前臂为米白交叠绷带（正面视图画面左侧），左前臂戴深棕护腕；两者在正面不可互换。绷带留 3–5 条可读边缘，不逐圈画密线。
- **下装与鞋：** 深炭裤，裤脚收进靴筒；靴头与靴底之间有一条浅灰米色分界线。

### 严格侧面（朝左）

- 只显示一个眼睛、一个眉、一只耳朵；鼻尖、嘴、下颌线必须形成干净侧影。禁止三分之四脸或双眼同时出现。
- 头发银白挑染位于角色右鬓，因此严格左侧面只显示符合视角遮挡的部分；不能为了镜头展示而把挑染挪到可见侧。
- 围巾扣点在肩部上方；布尾沿背后下垂，动作中向后摆。侧面围巾厚度约为头宽的 0.10–0.14，不能遮住记忆匣或手部攻击轮廓。
- 胸前衣襟、腰带叠层和靴底厚度要分层清楚。记忆匣侧面厚度约为正面宽度的 0.45；四根玻璃芯不要从侧面突出成尖刺。
- 远侧手臂、腿部比近侧部件暗 10–15% 明度，向后错开约 3–5% 肩宽；足部保持同一地面线，避免看起来像迈步姿势。
- 侧视图是动作生产的主视角。角色默认朝右的游戏朝向由镜像侧视资产得到；文字、非对称扣件和记忆匣玻璃芯不得被错误重绘或翻转逻辑打乱。

### 背面

- 后脑发束从头顶向颈部收拢，保留银白挑染从角色右侧绕过头部的少量边缘，不在后脑另添大白块。
- 外套背部以中缝为中心，肩胛处有两道结构缝；背面不加徽章、披风或第二件背包。
- 围巾仍固定在角色左肩，沿背部左侧垂到膝下；背面的围巾磨损边缘要和正面、侧面为同一块布连续延伸。
- 腰带从背面绕过，中央前置记忆匣不应在背后重复出现；后腰最多保留一条窄皮带环。
- 角色右臂绷带、左臂护腕按左右延续：背视下会出现在与正面相反的画面侧，不可按画面左右机械复制。
- 裤子后片有两条口袋缝线，膝后不加硬甲；靴跟比靴头略窄，浅色鞋底连续包边。

## 5. 像素精灵规格（历史：Blender 原生低分辨率渲染）

本节记录 V2/V3 当时的像素规格，2026-09-27 起已停用。现行导出是文首的 384×256、根点 (176, 246)。

当时把三视图当作高分辨率像素画参考，动作帧由 Blender 场景直接以原生低分辨率渲染，不先输出平滑大图再用滤镜伪造像素。角色轮廓和光影在最终像素网格上构成像素簇；同一段动作内相机、比例和根点保持固定。

| 参数 | 当时规格 |
| --- | --- |
| 原生单帧画布 | 256 × 192 px，PNG RGBA，透明背景，8 bit |
| 游戏显示倍率 | Godot 最近邻精确放大 3×；内容尺寸 768 × 576 viewport px |
| 目标角色高度 | 待机约 148 px；靴底至发顶，占画布约 77% |
| 垂直锚点 | 靴底根点 y = 176 native px，待机头顶 y ≈ 28；Godot 中根点对应 viewport y = 530 |
| 地面根锚点 | (112, 176) native px；Blender 摄像机/角色 Root 和 Godot Sprite 锚点共用 |
| 静止身体宽度 | 原生约 60–76 px；围巾/剑按动作扩展，任何帧至少留 2 native px 透明边 |
| 头部高度 | 原生约 26–30 px；眼睛约 2 px；轮廓和关键识别线至少 1 px |
| 关键识别最小宽度 | 银发亮点 ≥ 2 native px；红围巾主体 ≥ 4 px；腰匣可见宽度 ≥ 7 px |
| Blender 栅格采样 | 正交相机、固定约 5.647 单位垂直范围（34 px/单位）、Eevee 单采样，无时间抗锯齿模糊 |
| Godot 过滤 | `CanvasItem.TEXTURE_FILTER_NEAREST`；不在运行时缩放到非整数像素倍率 |
| 帧文件 | V3 分件帧路径已随图删除，见 [清理记录](2026-09-27-旧序列图清理记录.md)。不保留指向已删 V2 帧表的链接 |

当时的绘制规则是：

1. 像素由 Blender 以 256 × 192 原生渲染产生；禁止先渲染 384 × 512 平滑图再整体缩小。
2. 每个原生像素在 Godot 内复制为 3×3 像素块；不使用双线性/双三次过滤，也不在镜头缩放时产生非整数倍率。
3. 重要轮廓至少 1 native px 连续宽；脸、手指、扣件等细节合并成形状明确的像素簇，不放孤立噪点。
4. 每个材质以基色、暗部、亮部为主；布料暗褶、皮革磨损和金属亮点用有方向的短像素簇，不加均匀噪点。
5. 围巾尾、衣摆、头发尖端和挥砍弧线的最大范围都留在 256 × 192 内，边缘至少留 2 px；不逐帧自动裁切。
6. 靴底根点与角色 Root 锚点的水平、垂直漂移不超过 1 native px；上身前倾不改变地面基线，实际位移由游戏逻辑驱动。
7. 透明区域保持 alpha=0，角色像素为 alpha=255；不让抗锯齿半透明边在最近邻放大后形成脏色光圈。

## 6. 可拆分对象与命名（历史）

V3 当时的对象名是 `Body_*`、`Equipment_Sword` 与 `FX_Slash_*`，挂在 `HeroRig` 骨架上。实现文已删，删除范围见 [清理记录](2026-09-27-旧序列图清理记录.md)。下表是当时拟定、并未在现行整帧路线落地的部件拆分：头部仍包含头发，记忆匣仍包含四芯，没有拆到可独立换色的最细层级。V3 原图集保留的是生成稿色阶，没有量化成严格三色调色板；表中色值当时预备给手工修帧用。

当时建议 Blender 对象采用前缀 `Hero_`，装备和布料独立挂接；模型结构不把身份、技能判定或解锁条件写进网格。

| 对象名 | 组成 | 当时的连接/替换规则 |
| --- | --- | --- |
| `Hero_Head` | 头、耳、面部 | 挂 `Head`；表情细节后续可独立替换 |
| `Hero_Hair_Main` / `Hero_Hair_SilverLock` | 主发型、右鬓挑染 | 挑染与头部同骨骼；不作为独立技能或特效 |
| `Hero_Torso_Undershirt` / `Hero_Coat` | 内衫、外套、衣尾 | 外套前襟与左右衣尾可拆，身体动作共享骨骼 |
| `Hero_Scarf` / `Hero_Scarf_Tail` | 肩部围巾、末端布尾 | 固定在角色左肩；尾端可挂 `Scarf_Tail` 摆动骨 |
| `Hero_Arm_Right_Bandage` | 右臂绷带 | 与前臂骨骼绑定；替换为护具不更改身体动作 |
| `Hero_Arm_Left_Bracer` | 左臂护腕 | 独立装备槽；层级高于袖口、低于手部 |
| `Hero_Memory_Capsule` | 黄铜匣体、四枚玻璃芯 | 固定在腰带中心；四芯可单独替色/显隐，不随技能逻辑硬编码 |
| `Hero_Belt` / `Hero_Trousers` / `Hero_Boots` | 腰带、裤装、双靴 | 按 Root、Pelvis、腿骨拆分；两脚底高度统一 |
| `Equipment_Sword_*` | 剑身、护手、握柄、剑首 | 装备槽挂在手部枢轴；当时的设定图不含武器 |

当时的公共动作由身体骨架和装备挂点组成。待机、跑步、跳跃、近战只定义姿态片段；解锁、道具、伤害和冷却放在游戏数据层，不做成角色模型部件。这些 `Hero_*` 对象在现行 v4 整帧里不存在。

## 7. 动作中的造型连续性（历史检查项）

下列检查写于 Blender 分件路线。围巾、挑染、腰匣和左右臂的识别关系仍以第 1–3 节为准；这里只保留当时怎么查。

- 斩击预备时围巾向后蓄势；挥击峰值时围巾尾和外套尾朝运动反方向拉开；收势后布料回落。红布不穿过头、脸、手或记忆匣。
- 头发挑染跟随头部整体运动，不单独闪烁；银白区域面积在帧间保持近似不变。
- 腰匣固定在骨盆前中线，四芯不跳位、不翻序；胸口缝合痕随衣襟遮挡，不像发光 UI。
- 右臂绷带和左臂护腕的左右辨识保持一致；镜像时用引擎水平翻转完整帧，不交换角色自身的左右定义。
- 裤腿、靴子和手部保持明确前后层次；武器挥动时刀刃不遮住腰匣超过连续 3 帧。
- 每个动作至少检查起势、蓄力、接触/峰值、回收、结束；缩到 96 px 全身高时仍要读出主剪影。

## 8. 交付与验收（历史）

当时的验收分三视图和 256×192 精灵帧两套。三视图参考图 `reference/2026-09-26-主角三视图像素重绘.png` 仍在；256×192 与 3× 放大只适用于已删除的 Blender 帧，不适用于 v4。

### 像素画三视图验收

- 正、严格侧、背三视图均完整入画，头顶、围巾末端、靴底不被裁掉。
- 三视图头身高差 ≤ 2%；肩、腰、膝、靴底的水平对照偏差 ≤ 2%H；像素簇方向和服装明暗逻辑一致。
- 四个主识别点（红围巾、腰匣、银发、左右臂不对称）在对应视图位置一致。
- 胸口是断开的暗红缝合痕，不画成金属胸针；背视左臂是皮护腕，右臂是米白绷带。
- 无额外人物、重复装备、错向侧脸、漂浮配件或水印。

### 精灵帧验收

- 文件尺寸、颜色空间、透明通道一致；所有帧同一相机、同一比例和 Root 锚点。
- 在 256 × 192 原生尺寸下轮廓仍清晰；3× 最近邻显示时无颜色光圈和软化边。
- 用网格或差分检查脚底漂移、衣服穿插、武器脱手和透明边缘；不在自动紧裁后逐帧改变画布。
- 造型和像素簇以 `reference/2026-09-26-主角三视图像素重绘.png` 为依据。
