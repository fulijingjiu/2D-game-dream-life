## Godot 运行

在项目内层 `2d-game/` 目录运行：

```bash
bash prototype/2d_pipeline/v3/run_demo.sh
```

点击 Attack 或按空格播放横斩；动作结束回到待机。Previous / Next 逐帧查看，Speed 切换慢放，Sword / Effect 切换独立图层。首次运行会自动导入素材。

## 本轮交付范围

一名角色、一把剑、4 帧循环待机、12 帧完整横斩。单帧 256×192 RGBA，横斩总时长 760 ms；固定根点 (112,176)。角色由真实骨架驱动的 2.5D 分层贴图模型生成，支持在 Blender 时间轴中查看和调整。

外观、武器、动作分别由 `v3/config/` 下的三个配置文件管理。身体、武器、手部前景与刀光按层导出。源码与重建命令详见 [V3 实现与验收](2026-09-26-V3完整动作实现与验收.md)。V2 文档仅保留历史参数，当前使用 V3。

## 已检查与仍有限制的部分

已检查模型实际关节位置、握持点、脚底、画布边界、首尾衔接、分层像素合成及 Godot 播放逻辑。已查看完整逐帧检查图。浏览器工具限制了 `file://` 自动打开，离线 HTML 未通过浏览器交互自动化实测；可用 GIF 直接查看动作。

这套模型服务固定侧视镜头；背向和大幅透视动作需要额外分件。当前还没有敌人、伤害判定、奔跑、其他角色或声音。
